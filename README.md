# LeetCode Tree Visualizer

A web-based binary tree visualizer that converts comma-separated input into a fully rendered tree structure.

## 💡 Features
- Dynamic rendering of binary tree nodes
- Uses BFS to structure tree levels
- Edge rendering with Bezier curves
- Supports custom node values and layout scaling

## 🛠 Tech Stack
- JavaScript
- HTML5 Canvas
- BFS Algorithm
- CSS

## 🧪 Input Format
Comma-separated values (e.g., `1,2,3,null,4,5`), similar to LeetCode-style trees.
