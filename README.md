# 🌳 LeetCode Tree Visualizer

A web-based binary tree visualizer that converts comma-separated input into a fully rendered tree structure. Inspired by LeetCode’s visual tree format.

## ✅ Built-In

- 📥 Sample tree inputs for quick visualization  
- 🔗 BFS-based node structuring  
- 🧠 Bezier curves for dynamic edge rendering  
- 🎛️ Auto layout adjustment based on depth  
- 🧹 Reset / Clear canvas option  
- 🛑 Input validation with graceful fallback  
- 📱 Responsive rendering for various screen sizes  

---

## 🧪 Input Format

Comma-separated values (e.g., `1,2,3,null,4,5`), similar to LeetCode-style binary trees.
